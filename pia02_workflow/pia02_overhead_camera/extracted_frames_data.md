# Extracted Frames Data

Generated by `image_extraction.py` from overhead camera videos in the participant data directory.

**Output location:** `\\192.168.1.104\home\piano\data\overhead_camera\extracted_frames`

## Source

Videos are read from `\\192.168.1.104\home\piano\data\{participant_id}\overhead camera\*.MP4`.

## Folder Structure

```
extracted_frames/
├── 009/
│   ├── 009.csv
│   ├── 009-0-10-fx30_2_2274.png
│   ├── 009-0-51650-fx30_2_2274.png
│   ├── 009-1-10-fx30_2_2275.png
│   ├── 009-1-75158-fx30_2_2275.png
│   └── ...
├── 010/
│   ├── 010.csv
│   └── ...
└── ...
```

Each participant has a folder named by their numeric ID (e.g., `009`).

## Image Files

**Filename format:** `{participant_id}-{video_index}-{frame_index}-{video_stem}.png`

| Field            | Description                                                        | Example        |
| ---------------- | ------------------------------------------------------------------ | -------------- |
| `participant_id` | Numeric participant ID                                             | `009`          |
| `video_index`    | 0-based index of the video file (sorted alphabetically)            | `0`            |
| `frame_index`    | Frame number extracted from the video                              | `10` or `51650`|
| `video_stem`     | Original video filename without extension                          | `fx30_2_2274`  |

Two frames are extracted per video:
- Frame **10** (near the beginning)
- Frame **total_frames - 10** (near the end)

Videos with zero frames are skipped. Existing images are not overwritten.

## CSV File

One CSV per participant: `{participant_id}.csv`

| Column                         | Description                                                  |
| ------------------------------ | ------------------------------------------------------------ |
| `participant_id`               | Numeric participant ID                                       |
| `video_name`                   | Original `.MP4` filename                                     |
| `reference_image`              | To be filled manually — reference image for camera alignment |
| `camera_shifted_during_trial`  | `1` if the camera shifted during the trial, empty otherwise  |
| `note`                         | To be filled manually — free-form notes                      |

The CSV is auto-generated with one row per video. The last three columns are left empty for manual annotation.
